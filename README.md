ReNative

Um projeto de Minecraft para Android, focado em expansão, personalização e modificações.

Recursos

- Suporte a mods.
- Sistema multiplayer para até 8 jogadores na mesma rede Wi-Fi.
- Possibilidade de expandir funcionalidades através de modificações.

Documentação

- "MULTIJOGADOR.md" (MULTIJOGADOR.md) — informações sobre o multiplayer.
- "MODDING.md" (MODDING.md) — documentação para criação de mods.
